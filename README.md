# PrintoLINE v2

スマートフォンで使える、PDFプリントの文章抽出・JPEG変換ツールです。

## 現在の試作版でできること
- PDFファイルをブラウザ内で読み込む
- パスワード付きPDFの読み込みを試みる
- PDFに埋め込まれた文字を抽出して編集する
- 画像だけのPDFは、OCRボタンで文章を読み取る（手動実行）
- PDFの各ページをJPEGに変換して表示する
- JPEGをページごとに保存する
- 対応端末では文章や複数JPEGを共有メニューへ渡す
- PWA用の設定とホーム画面アイコンを用意する

## 大切な注意
- OCR（文字認識）は、ボタンを押したときだけ Tesseract.js（日本語＋英語）で端末内実行します。初回は言語データの読み込みに時間がかかり、精度は完全ではありません。PDFや画像はサーバーへ送りませんが、ライブラリと言語データはCDNから取得します。
- PDFと抽出テキストはアプリのサーバーへアップロードしません。PDF.jsライブラリはCDNから読み込みますが、PDFファイル自体はブラウザ内で処理します。
- 外部ライブラリの配信先を含め、公開前に通信内容を検証してください。
- LINEへの複数画像一括共有は端末・ブラウザ・LINEの対応状況によって動作が異なります。
- フッターに、OFUSEへの控えめな案内リンク「改善のアイディア・応援はこちら」を設置しています（`index.html` と `script.js` の `OFUSE_URL`）。
- GoatCounter（wel-be.goatcounter.com）でアクセス数のみを匿名集計します。PDFや抽出した文章は送信されません。
- ブラウザ内の作業内容は保存されません。
- 試作版のため、公開前に実機テストと不具合修正が必要です。

## GitHub Pagesで公開する基本手順
1. リポジトリ `printoline-v2` にこのフォルダ内のファイルをアップロードします。
2. GitHubリポジトリの Settings → Pages を開きます。
3. Build and deployment の Source を `Deploy from a branch` にします。
4. Branch を `main`、フォルダを `/(root)` にして Save を押します。
5. 数分待ち、表示されたPages URLを開いて動作確認します。

## 開発メモ
PDF.jsは現在 CDN のバージョン 3.11.174 を参照しています。将来の更新では、`index.html` と `script.js` のバージョン指定を合わせて変更してください。
